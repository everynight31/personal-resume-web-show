# 网页简历（含「粘贴一键识别」）

> 🔗 在线预览：https://everynight31.github.io/personal-resume-web-show/

一个纯静态单页简历，现代简约风格，零依赖、零构建。
额外加了一套「粘贴简历文本 → 一键识别 → 逐字段校对 → 应用到简历」的工具。

双击 `index.html` 就能用：不需要服务器、不需要联网、不需要安装任何东西。

---

## 怎么用

### 看简历

打开 `index.html` 即可。右下角有两个悬浮按钮：主题切换（🌙/☀️，默认跟随系统）和「粘贴识别」。

首页「浏览简历」可直接跳到第一个可见章节；「打印 / 导出 PDF」可打开浏览器打印窗口。
手机上的编辑面板按「输入 → 校对 → 应用」纵向滚动，所有操作都可以通过键盘访问；打开面板后焦点会进入弹窗，按 `Esc` 关闭并返回入口。

### 一键识别

1. 点右下角「粘贴识别」（快捷键 `Ctrl/Cmd + K`，也可以直接用 `index.html#parser` 打开）
2. 左侧输入框里已经预填了一份带注释的模板，照着它把你的内容填进去
   - 模板里以 `#` 开头的说明行会被自动忽略，不用手动删
   - 带 `【小标题】` 的文本识别率最高（≈95%）
   - 不想写小标题也行：整段原始简历直接粘贴，会自动分段（准确率降到 ~70-85%）
3. 点「一键识别」
4. 右侧出现识别结果，按区块折叠成卡片，可逐字段校对，输入框铺满整行，右侧实时预览
   - **勾选 = 这一项要不要出现在简历里**。右侧预览就是点应用后的结果，两者一定一致
   - 粘的文本里写了什么就有什么：没写「求职意向」就不会出现求职意向；没写的模块默认不勾选
   - 已有但这次没识别到的模块标着「现有模块（本次未识别到）」，内容留空、默认不勾选。想保留就勾上，想改就直接在框里输入（输入后自动勾上）
5. 点「应用到简历」→ 主页面立即重绘，数据存进浏览器
   - 没勾的模块只是**不显示**，内容仍留在「设置 → 简历模块」里，可以从那里彻底删除
6. 点错了就「撤销上次应用」

> 不粘贴也能用这个面板。还没识别过任何东西时，面板会直接列出简历里已有的全部内容，可以直接改、直接应用 —— 相当于一个简历总编辑器。

### 数据放在哪

三层，优先级从高到低：

| 层 | 位置 | 说明 |
|---|---|---|
| 本地修改 | 浏览器 `localStorage` | 网页上改过的内容，刷新不丢；换电脑/清缓存会丢 |
| 默认数据 | `data.js` | 想永久改内容，直接改这个文件最省事 |
| 备份 | 「设置 → 导出 JSON」 | 换电脑前记得导一份，或点「恢复默认数据」清掉本地覆盖 |

### 背景效果

右下角「粘贴识别」→「设置」→「背景效果」里可以换，共 9 种：流动水面（默认）、星光漫游、水墨晕染、粒子连线、气泡上浮、星空闪烁、声波流动、流星拖尾、关闭。全部本地绘制，不联网、不加载任何库；选择会记在浏览器里，刷新后保持。

「水墨晕染」使用带纤维质感的宣纸底色与不规则毛边墨晕：点击落墨，划动留下小墨痕，墨迹缓慢扩散、淡去。白天是暖纸墨青，夜间是深纸银灰；标题采用墨色与朱砂印记装饰，正文保持稳定。纸纹和墨迹预先缓存，每帧只调整位置、半径和浓淡；交互墨迹最多保留 14 处，约 12 秒消退。支持强度调节、背景保存及系统减少动态效果。

「星光漫游」是新增的独立选项：星云底色、缓慢闪烁的星点与十字星芒，划过留下星尘，点击绽放小范围星光，偶尔出现流星。文字同步切换为星辉配色，深色下是银白、淡紫与淡金；亮色下使用更清晰的靛蓝。鼠标与滚动带来轻微视差，交互星尘最多保留 32 颗并自动消退；约 30 帧绘制，减少动态效果时保持静态。

流动水面带缓慢流动的折射光纹：鼠标划过、点击或手指滑动会激起涟漪，页面滚动带来轻微视差；「效果强度 / 粒子密度」可调整水光强度。已保存的背景选择会保留，旧用户可在设置里选「流动水面」或点「恢复默认背景」。

水面使用 WebGL 加速、限制绘制分辨率并以约 30 帧运行；不支持 WebGL 时回退为 Canvas 流动波纹。隐藏标签页、关闭背景或打印时停止动画调度；系统开启「减少动态效果」时只显示静态水面。

水面下的文字也会同步变成海蓝 / 青白配色：姓名带缓慢渐变流光，姓名、求职意向、章节标题和技能标签轻轻浮动，正文与编辑器保持稳定。切换到其他背景后恢复普通文字；系统「减少动态效果」会关闭文字浮动与流光动画，打印时使用清晰的静态排版。

### 换头像

「粘贴识别」→「设置」→「头像」→「选择照片」。照片会在浏览器里自动裁成竖版证件照（480×640）再存进 localStorage，不联网、不上传。上传时自动对准人脸取景，构图不满意可拖动「取景位置」滑块调整。

### 增删简历模块

「设置」→「简历模块」：可新建模块（按名字自动推荐版式）、调整顺序、删除、改内容，改动即时生效，删除可撤销。

### 打印 / 导出 PDF

浏览器 `Ctrl+P` → 目标选「另存为 PDF」。会自动隐藏所有工具界面（粒子背景、悬浮按钮、抽屉、导航）并强制浅色 + A4 分页。

也可使用首页「打印 / 导出 PDF」按钮。导出的是当前已应用的简历，校对中的草稿需要先应用。

### 本地验证

运行 `node tools/serve.js`，然后访问终端显示的本地地址。项目不需要安装依赖。

回归检查分别运行 `node tests/helpers.test.js`、`node tests/parse.test.js`、`node tests/panel.test.js`、`node tests/render.test.js`、`node tests/store.test.js` 和 `node tests/particles.test.js`。

### 部署到 GitHub Pages

纯静态，直接托管即可：

1. 把 `resume-web/` 里的文件推到仓库（`main` 分支）
2. 仓库 `Settings → Pages → Source` 选 `Deploy from a branch`，分支选 `main` / 根目录
3. 等一两分钟，访问 `https://<用户名>.github.io/<仓库名>/`

也可以把整个目录丢到 Vercel / Netlify / Cloudflare Pages，无需任何构建配置。
