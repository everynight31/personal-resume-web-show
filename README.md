# 网页简历（含「粘贴一键识别」）

一个**纯静态单页**简历，现代简约风格，零依赖、零构建。
额外加了一套「粘贴简历文本 → 一键识别 → 逐字段校对 → 应用到简历」的工具。

**双击 `index.html` 就能用**：不需要服务器、不需要联网、不需要安装任何东西。

---

## 一、怎么用

### 看简历
打开 `index.html` 即可。右下角有两个悬浮按钮：主题切换（🌙/☀️，默认跟随系统）和「粘贴识别」。

### 一键识别
1. 点右下角 **「粘贴识别」**（快捷键 `Ctrl/Cmd + K`，也可以直接用 `index.html#parser` 打开）
2. 左侧输入框里**已经预填了一份带注释的模板**，照着它把你的内容填进去
   - 模板里以 `#` 开头的说明行会被自动忽略，不用手动删
   - 带 `【小标题】` 的文本识别率最高（≈95%）
   - **不想写小标题也行**：整段原始简历直接粘贴，会自动分段（准确率降到 ~70-85%）
3. 点 **「一键识别」**
4. 右侧出现识别结果，**按区块折叠成卡片**：
   - 面板列出的是**简历的全部模块** —— 本次识别到的，加上已有但这次没识别到的
     （后者标着「现有模块（本次未识别到）」）。所以一次无关的粘贴不会让已有模块消失，
     在设置里新建的模块也一定能在面板里找到并就地编辑
   - 每张卡片头部就是「勾选框 + 区块名 + 摘要」，一眼看出这一组选了几项、缺几项
   - 点卡片头部（或右侧箭头）展开/收起；顶部有「展开全部 / 收起全部」
   - 展开后每个字段一行：字段名 + 「已识别 / 未识别到」徽标，输入框在下方**铺满整行**
   - 每个字段前面有勾选框，可单独取消；没识别到的会标红提示，**留空就不会覆盖原有内容**
   - 最右侧是**实时缩略预览**，改一个字就能看到最终效果
5. 点 **「应用到简历」** → 主页面立即重绘，数据存进浏览器
   - 底部操作区是吸底的，结果再多也不会被挤出可视区
   - **只有勾选的区块会被写入**；没勾的、以及本次没识别到的模块，内容原样不动
6. 点错了就 **「撤销上次应用」**

> **不粘贴也能用这个面板。** 还没识别过任何东西时，面板会直接列出简历里已有的全部内容，
> 可以直接改、直接应用 —— 相当于一个简历总编辑器。
> 这也是「设置 → 简历模块」新建的模块立刻能看到的地方。

### 数据放在哪
三层，优先级从高到低：

| 层 | 位置 | 说明 |
|---|---|---|
| 本地修改 | 浏览器 `localStorage` | 网页上改过的内容，刷新不丢；换电脑/清缓存会丢 |
| 默认数据 | `data.js` | 想永久改内容，直接改这个文件最省事 |
| 备份 | 「设置 → 导出 JSON」 | 换电脑前记得导一份，或点「恢复默认数据」清掉本地覆盖 |

> **改了 `data.js` 但网页没变化？** 那是被上面的 localStorage 覆盖挡住了。
> 本项目用「数据版本号」自动处理这件事：`data.js` 的 `meta.dataVersion` 一旦变化，
> 浏览器里那份旧覆盖会被**自动丢弃**并在页面右下角弹出提示。
> 所以**你改完 `data.js`，记得把 `dataVersion` 也 +1**：
>
> ```js
> meta: { dataVersion: 3, /* … */ }
> ```
>
> 手动清也可以：抽屉 →「设置」→「恢复默认数据」。

### 背景效果
右下角「粘贴识别」→「设置」→「背景效果」里可以换，共 **6 种**：

| 特效 | 效果 |
|---|---|
| 粒子连线 | 漂浮的光点自动连成网，鼠标能推开它们（默认） |
| 气泡上浮 | 大小不一的空心气泡缓缓上升，鼠标附近会加速 |
| 星空闪烁 | 星点呼吸式明灭，偶尔划过一颗流星 |
| 声波流动 | 多条正弦曲线横向流动，随鼠标起伏 |
| 流星拖尾 | 几道流光缓慢划过，留下渐隐的长尾 |
| 关闭 | 不绘制任何背景，页面最轻量 |

选择会记在浏览器里，刷新后保持；下面还有 **粒子密度** 滑块（40%~200%）可以微调浓淡。
全部是自绘 Canvas，不联网、不加载任何库；切走标签页会自动停画，`prefers-reduced-motion`
开启时只画一帧静态图。

### 换头像
「粘贴识别」→「设置」→「头像」→「选择照片」。
照片会在浏览器里自动裁成竖版证件照（480×640）再存进 localStorage，
**不联网、不上传**。实测一张 979 KB 的手机照片压完约 13 KB。

**取景是自动对准的**：上传时会尝试用浏览器的人脸检测找到人脸位置，
把人脸放在画面从顶部往下约 38% 处（证件照的常见构图）。浏览器不支持人脸检测
（Firefox 等）或没检测到人脸时，会退回按人像常规取景 —— 所以这条链路不依赖它也能用。

如果构图还是不满意，下面会出现 **「取景位置」滑块**：往左拖看上方、往右拖看下方，
拖动时实时重裁，不用重新选文件。不想用照片就点「移除头像」，页面显示姓名首字。

> 早先这里写死过 `object-position: 50% 8%`，等于把某一张照片的构图硬编码进 CSS，
> 换张照片就歪。现在取景在上传时就烘焙进图片本身，CSS 只负责摆正。
>
> **`assets/avatar.svg` 的构图是按圆形裁切排的。** 头像在页面上显示成 124px 的圆，
> 圆外的内容根本看不到 —— 所以 SVG 内部画了一个 `clipPath` 圆，人像和装饰线都限制在圆内，
> 并按「圆内居中略偏上、肩部留出完整弧线」来定位。
> 改这个文件时注意：**不要按 320×400 整幅画布去居中**，那样在圆里会显得偏下。
> `tests/helpers.test.js` 里有 21 项断言守着这件事（`object-position` 必须是中性值、
> 人像必须在圆内、上下留白要均衡、提示文字必须在圆外）。

### 增删简历模块
「设置」→「简历模块」：

- **新建**：填名称 → 点「+ 新建模块」。输入名称时会按名字**自动推荐版式**
  （「荣誉奖项」→要点列表、「发表论文」→经历卡片、「专业技能」→标签），建好后可随时改
- **调整顺序**：卡片右上角的 ↑ ↓，**这里的顺序就是页面上区块的顺序**
- **删除**：卡片右上角的垃圾桶，或直接把鼠标移到页面上那个区块、点右上角出现的垃圾桶
- **改内容**：展开卡片直接填。每种版式的字段不一样，编辑器会跟着变
  （标签版式分「分组名 + 技能词」，经历卡片分「名称/时间/角色/地点 + 正文」…）
- 每次改动都会立刻反映到页面和右侧实时预览；删除可以「撤销」找回

### 打印 / 导出 PDF
浏览器 `Ctrl+P` → 目标选「另存为 PDF」。会自动隐藏所有工具界面（粒子背景、悬浮按钮、
抽屉、导航）并强制浅色 + A4 分页。

### 部署到 GitHub Pages
纯静态，直接托管即可：

1. 把 `resume-web/` 里的文件推到仓库（`main` 分支）
2. 仓库 `Settings → Pages → Source` 选 `Deploy from a branch`，分支选 `main` / 根目录
3. 等一两分钟，访问 `https://<用户名>.github.io/<仓库名>/`

也可以把整个目录丢到 Vercel / Netlify / Cloudflare Pages，无需任何构建配置。

## 三、识别器是怎么工作的

`parser.js` 有两档能力，自动选择：

### A. 模板模式（有小标题，准确率 ≈95%）
按行扫描，识别三种标题写法：
- `【教育背景】` 方括号标题
- `## 教育背景` Markdown 标题（`# 示例姓名` 这种一级标题会被当姓名）
- `教育背景` 单独成行

然后按区块类型分别抽取：

| 区块 | 结构 | 抽取要点 |
|---|---|---|
| 教育背景 | `timeline` | 日期区间 → `2021.09 – 2025.07`；分隔符 `\|`、制表符、两个以上空格都能切；`（本科）` 这类括号里的学位会拎出来拼成 `本科 · 某专业` |
| 项目/工作/工程设计 | `cards` | 短标题行 = 新项目；`技术实现：xxx` 这类带标签的行 = 卡片内小块；以句号收尾后出现的短行也判定为新标题 |
| 相关技能 | `tags` | 按 `、，；/` 切分，再拿词表匹配；命中词表的用规范写法（避免「遗传算法应用」这种尾巴），并自动分主/次 |
| 研究兴趣 / 综合能力 / 获奖 | `list` | `小标题：内容` → `{title, text}` |

**可选区块**：识别器还支持「成绩 / 评级条」，形如 `综合测评：总分90 数学95 专业课92`，
会渲染成 Hero 下方的一排分数胶囊。**求职简历用不到，`data.js` 里不要写 `scores` 字段即可**；
考研复试、竞赛成绩单这类简历才需要。缺少成绩段不会影响识别完整度评分。

**同一份别名表**把不同说法映射到同一类区块，例如「技能特长」「专业技能」都进「相关技能」，
「工程设计」和「项目经历」是**两个独立区块**（你这份简历正好需要这个）。

### B. 自由文本降级（没小标题）
- 靠**关键词得分**分类（强关键词 ×3 + 弱关键词 ×1），而不是「命中第一个词」——
  这样「毕业设计做的是…」不会被误判成教育背景
- 纯日期行是分块信号；教育块里的连续日期行会留在一起（多条学历）
- 关键词信号弱的新块会继承上一块的类型，避免一段经历被劈成两个区块
- 最后用技能词表把**全文扫一遍**补出「相关技能」，所以自由文本至少技能不会丢

识别完会给一个**完整度评分**（检查姓名、联系方式、教育、项目、技能、列表区块是否都拿到），
低于 75% 时状态栏会变黄提示重点核对。

### C. 大模型增强（默认关闭）
「设置」里可以填 DeepSeek 的 API Key，打开后对**乱七八糟的自由文本**效果明显更好。
- Key 只存在你自己的浏览器 localStorage，只发往你自己填的 Base URL
- 三种调用策略：总是优先 / 仅本地识别差时才调 / 只手动调
- 大模型调用失败会自动回退到本地规则解析，不会白干
- 提示词里明确要求「原文没有的信息必须留空，不许推测」

### 想改的地方在哪
- **改简历内容** → `data.js`，或者在网页「设置 → 简历模块」里直接改
- **改浏览器标签页标题** → `data.js` 里的 `meta.title`（留空则自动用「姓名 - 简历」）
- **换头像** → 网页「设置 → 头像」上传，或在 `data.js` 里把 `profile.avatar` 指向自己的图片
- **加一种模块版式** → `render.js` 里加一个 `renderXxx(section)`，并在 `renderInto` 的 switch 里挂上
- **改版式推荐规则**（新建模块时按名字猜） → `js/helpers.js` 的 `SORT_RULES`
- **改校对面板显示哪些模块** → `js/helpers.js` 的 `mergeSections`（现有区块与识别结果怎么合并）
- **改配色/字号/圆角** → `style.css` 顶部的 CSS 变量（`:root` 与 `html[data-theme="dark"]`）
- **改技能词表** → `js/skills.js` 里的 `MAIN` / `AUX` 数组
- **加区块别名**（比如你的简历用「科研经历」） → `js/parser.js` 里的 `SECTION_MAP`
- **改打印排版** → `print.css`

### 加一种背景特效
`js/particles.js` 里 `EFFECTS` 是一张「特效注册表」，每个特效只要实现三个东西：

```js
EFFECTS.myEffect = {
  meta: { id: 'myEffect', name: '我的特效', desc: '一句话说明' },
  init: function (w, h, rnd) {
    // 建你的粒子数组，rnd() 是带种子的伪随机，保证尺寸不变时布局稳定
    return {
      frame: function (dt) {
        // 每帧画一次；dt 是秒，乘 60 就是「按 60fps 归一化」的系数
        clear(w, h);
        ctx.fillStyle = withAlpha(colors.dot, 0.5);
        // …
      }
    };
  }
};
```

再把 id 加进 `EFFECT_LIST`，设置页会自动多出一张带缩略图的卡片，**不用改 UI 代码**。
缩略图是纯 CSS 画的（`style.css` 里的 `.effect-thumb.t-<id>`），加几笔即可。

## 五、已知边界

- `localStorage` 在「无痕模式」或某些浏览器隐私设置下不可用，此时只能改 `data.js`
- 自由文本降级模式对**没有任何结构线索**的长文本，仍可能把两段经历并成一个区块，需要在校对面板里手动拆
- `transform: scale()` 会让缩放后的元素被浏览器判定为不可见而不绘制，所以缩略预览用的是 CSS `zoom`
- 打印分页只能做到「卡片/条目不跨页」，无法精确控制每页放什么；要精确排版建议导出后用 Word 微调
